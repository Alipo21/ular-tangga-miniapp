# 🎲 Ular Tangga Mini App (Telegram)

Game **Ular Tangga** (Snakes & Ladders) untuk Telegram Mini App.

## Cara Main
- **2 pemain** (Pemain 1 merah, Pemain 2 biru)
- Lempar dadu, naik tangga 🪜, hindari ular 🐍
- Menang saat mencapai **posisi 100**

## Fitur
- Papan 10x10 (zigzag)
- 6 tangga: 3→22, 8→30, 28→84, 51→67, 71→91, 80→99
- 7 ular: 17→7, 54→34, 62→19, 64→60, 87→24, 95→75, 98→79
- Animasi dadu
- Dukungan Telegram WebApp (maksimal layar)

## Deploy
Repo ini di-host di **GitHub Pages** — buka `https://Alipo21.github.io/ular-tangga-miniapp/` untuk bermain.
